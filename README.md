**Vice Harbor** is a complete open-world crime game that plays offline in a desktop browser from static files — no build step, no assets, no network. Nico Ferrer washes up in Puerto Brisa with $120 and a reputation; fixer Marisol Vega, out of Cantina La Brisa, has work. Explore a seeded city of 14×11 blocks on foot or by car: steal any of six original car models (traffic drivers pop out and run), outrun a five-star wanted system with pursuing police cars and officers who get out and shoot, fight on foot with fists or a mouse-aimed pistol, sell clean cars to the Taller Reyes chop shop, and run Marisol's five-job story chain — First Wheels, Package Run, Heat, The Tiburon, and The Final Run — to be crowned Harbor King, then keep free-roaming. Full HUD with cash, health, wanted stars, a bust meter and a live minimap; day-to-dusk cycle; synthesized sound effects; progress saved to localStorage. All names, art, and story are original to this entry.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
